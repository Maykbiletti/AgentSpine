# Code of conduct

We want AgentSpine to be a constructive, safe, and welcoming project.

Be respectful, discuss ideas and evidence rather than people, protect personal context, and assume that identity and memory data may be sensitive even when it appears harmless. Harassment, discrimination, threats, doxxing, and publication of another person's private agent data are not acceptable.

Maintainers may edit or remove contributions and participation that violate these expectations. Serious concerns should be reported privately through the repository's security reporting channel rather than exposed in a public issue.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) while keeping this repository document concise.
